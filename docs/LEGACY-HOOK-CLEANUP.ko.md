# 이전 전역 훅 정리

dorms-check 0.3.0은 전역 훅 설치와 배포 차단 기능을 제거했습니다. 이전 버전이 사용자 설정에 넣은 항목은 업데이트만으로 사라지지 않아 정리 명령을 제공합니다.

## 상태 확인

~~~bash
npx -y github:shinnanchanguk/dorms-check#v0.3.0 hooks status --json
~~~

이 명령은 설정을 읽기만 합니다. Codex·Claude·Gemini·Antigravity의 현재 사용자 지정 경로와 기본 경로를 확인합니다. 예전에 사용했지만 지금은 지정하지 않는 별도 경로나 다른 호스트의 설치는 자동으로 찾지 못할 수 있습니다.

## 해제

~~~bash
npx -y github:shinnanchanguk/dorms-check#v0.3.0 hooks uninstall --json
~~~

`--agents codex,claude`처럼 일부만 선택할 수도 있습니다. 선택한 설정을 모두 읽어 구조를 확인한 뒤 원본을 `~/.dorms-check/backups/legacy-hooks-...`에 백업합니다. 출력의 `backup` 값이 원본 위치입니다.

Codex는 도름스 관리 표식으로 둘러싸인 블록만 제거합니다. JSON 설정은 도름스 명령 항목만 제거하며 같은 묶음 안의 다른 훅은 남깁니다. 수정한 설정, 읽지 못한 파일, 연결된 경로는 무리하게 바꾸지 않습니다. 원본을 구분하지 못하면 오류와 함께 남은 위치를 알려줍니다.

공용 실행 파일은 알려진 모든 설정에서 참조가 사라지고, 기존 설치 기록의 해시와 일치할 때 백업 후 제거합니다. 다른 에이전트의 참조나 사용자 수정이 남아 있으면 보존합니다. 다시 실행해도 다른 설정을 지우지 않습니다.

정리에는 현재 Node.js만 필요합니다. 이전 훅에 고정된 Node·Vercel·PowerShell 실행 파일을 찾거나 실행하지 않으며 배포 자격증명도 사용하지 않습니다. 설정을 읽어 둔 AI 앱은 정리 후 다시 실행하세요.

## 예전 명령의 결과

폐기한 배포 차단 명령과 옵션은 검사나 파일 저장 전에 `FEATURE_REMOVED`와 종료 코드 2를 돌려줍니다. 자동으로 일반 검사로 바꾸어 실행하지 않습니다. 점검을 원하면 기본 `scan` 명령을 새로 요청하세요.
